# 📚 Mozakra - مذاكرة

ابدأ مذاكرة مع الموقع ده ال هيساعدك تخلص كل التراكمات ال عليك و ينظملك وقتك عشان توصل للدرجة ال نفسك فيها بمساعدة الذكاء الاصطناعي و كله مجاناً

هذا المشروع يتم تطويره من اجل [جائزة الدولة المصرية للمدع الصغير 🇪🇬](https://ckp.eg/)

## ✨ المزايا الرئيسية

1. ذكاء اصطناعي يعملك جدول مذاكرة يومي مناسب ليك ⌚
2. تابع عدد ساعات دراستك و انجازاتك اليومية بشكل بسيط 📊
3. ذكاء اصطناعي يقسم الدروس و الواجبات ال عليك حسب ايام الاسبوع 📚
4. ذكاء اصطناعي يشرحلك اي حاجة انت مش فاهمها بشكل بسيط و سهل 👨‍🏫
5. ساعة بومودورو بمؤقت عشان تساعدك في الركيز و المذاكرة بشكل صح 🍅
6. تحويل الموقع ل PWA بحيث تضيفه عندك علي الشاشة الرئيسية بضغطة واحدة 📱
7. مدونات تساعد الطلبة في استخدام ادوات مجانية مختلفة تساعدهم في الدراسة 📄

**االموقع ده: 🌐**

- فيه واجهة سهلة (UI/UX) و فيه امكانية الوصول (Accessibility) 🎨💜
- مجاني بالكامل 🆓
- لكل الطلاب في مصر و الوطن العربي (حالياً) اياً كانت السنة الدراسية 👨‍🎓
- باللهجة المصرية 🇪🇬
- مفتوح المصدر (open source) 🔓 

## 🛠 الأدوات المستخدمة 

1. Next.js 
2. TypeScript
3. Tailwind CSS + ShadCN 
4. Turso + Drizzle ORM (database: SQLite)
5. Git/GitHub
6. DeepSeek + Google Gemini (تم الاستخدام في التطوير)
7. Hugging Face Spaces (AI)
8. Vercel (deployment)
