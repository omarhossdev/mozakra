# 📚 Thanaweya Student - طالب ثانوية

**طالب ثالثة ثانوي و شايف السنة صعبة؟؟ الموقع ده كنز ليك 🌟**

هذا المشروع يتم تطويره من اجل [جائزة الدولة المصرية للمدع الصغير 2027 🇪🇬](https://ckp.eg/)

## ✨ المزايا الرئيسية

1. 🤖 مساعد ذكي (نموذج مفتوح المصدر) يعملك جدول مذاكرة يومي وأسبوعي حسب نومك ومواعيد دروسك وأوقات فراغك، وبيدي أولوية للمراجعة قبل الامتحانات — وتقدر تعدّله يدوياً ⌚
2. 📊 تابع إنجازك اليومي وعدد جلسات التركيز والـ streak بشكل بسيط، مع XP وبادجات 🏅
3. 📚 المساعد الذكي يقسم الدروس والواجبات على أيام الأسبوع بحيث مفيش يوم مرهق، وينبهك "فاضل X أيام للامتحان ولسه مخلصتش الفصل Y"
4. 🍅 مؤقت بومودورو مدمج لجلسات تركيز وفترات راحة صح، وبيعدّي على مواد جدولك
5. 📱 الموقع PWA — تضيفه على الشاشة الرئيسية بضغطة، وكل الميزات الأساسية شغالة offline
6. 🔔 تنبيهات تليجرام اختيارية 100% عبر بوت مجاني يذكّرك بجدولك وامتحاناتك، وتتحكم فيها وقت ما تحب
7. 🇬🇧 حفظ و مراجعة كلمات الانجليزية المنهج كامل و مراجعة يومية عشان ما تتنساش
8. 🏆 Leaderboard بالـ XP — كل طالب ليه username، والترتيب بالـ XP بس، من غير بروفايل عام ولا تفاصيل شخصية
9. 📝 ملخصات مُراجَعة يدوياً — بخط اليد وبموافقة صاحبها، مع مراجعة copyright قبل النشر وتقييم
10. 📄 مدونات فيها ترشيحات لتطبيقات مجانية تساعد الطلاب و نصائح

**االموقع ده: 🌐**

- فيه واجهة سهلة (UI/UX) و فيه امكانية الوصول (Accessibility) 🎨💜
- مجاني بالكامل 🆓
- لكل الطلاب في مصر و الوطن العربي (حالياً) اياً كانت السنة الدراسية 👨‍🎓
- باللهجة المصرية 🇪🇬
- مفتوح المصدر (open source) 🔓
