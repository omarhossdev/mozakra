## 🌟 عن المشروع

**طالب ثالثة ثانوي وشايف السنة صعبة؟؟ الموقع ده كنز ليك 🌟**

**طالب ثانوية (Thanaweya Student)** هو منصة مذاكرة ذكية ومتكاملة مصممة علشان تشيل عنك ضغط الثانوية العامة. الموقع مبني بواجهة بسيطة مريحة للعين تدعم إمكانية الوصول (Accessibility) وباللهجة المصرية القريبة ليك، علشان يساعدك تنظم وقتك وتلتزم وتتابع تقدمك — حتى لو مفيش إنترنت.

> 🏆 *يتم تطوير هذا المشروع من أجل **جائزة الدولة للمبدع الصغير 2027** 🇪🇬.*

---

## ✨ المزايا الرئيسية

* 🤖 **مساعد ذكي لجدول المذاكرة:** مدعوم بنموذج ذكاء اصطناعي مفتوح المصدر يعملك جدول مذاكرة يومي وأسبوعي حسب ساعات نومك ومواعيد دروسك وأوقات فراغك، وبيدي أولوية تلقائية للمراجعة قبل الامتحانات — مع إمكانية التعديل اليدوي في أي وقت ⌚.
* ⚖️ **توزيع ذكي للمهام:** بيقسّم الدروس والواجبات على أيام الأسبوع بالتساوي بحيث مفيش يوم يكون مرهق، ويبعتلك تنبيهات استباقية زي *"فاضل X أيام للامتحان ولسه مخلصتش الفصل Y"*.
* 🍅 **مؤقت بومودورو مدمج:** جلسات تركيز وفترات راحة صحية متوصلة مباشرة بمواد جدولك الدراسي.
* 📊 **تتبع الإنجاز والـ Streaks:** تابع إنجازك اليومي وعدد جلسات التركيز وحافظ على الـ streak الخاص بيك، واكسب نقاط XP وبادجات تشجيعية 🏅.
* 🏆 **لوحة شرف تحترم خصوصيتك (Leaderboard):** نافس زمايلك بالـ XP باستخدام اسم مستخدم (username) فقط — من غير بروفايل عام، صور، أو أي تفاصيل شخصية.
* 📱 **تطبيق ويب يعمل بدون إنترنت (Offline-First PWA):** تقدر تضيفه على الشاشة الرئيسية لموبايلك أو جهازك بضغطة واحدة، وكل الميزات الأساسية شغالة offline بالكامل.
* 🔔 **تنبيهات تليجرام اختيارية 100%:** اربط حسابك ببوت تليجرام مجاني يذكّرك بجدولك وامتحاناتك، وتقدر تتحكم فيها أو توقفها وقت ما تحب.
* 🇬🇧 **حفظ ومراجعة كلمات الإنجليزي:** احفظ وراجع كلمات منهج الإنجليزي بالكامل بنظام التكرار المتباعد اليومي (Spaced Repetition) علشان متتنساش أبداً.
* 📝 **ملخصات مُراجَعة يدوياً:** ملخصات بخط اليد ومنظمة، تمت مراجعتها للتأكد من جودتها واحترام حقوق الملكية (Copyright) بموافقة أصحابها.
* 📄 **مدونة ومصادر للطلاب:** مقالات وترشيحات لأفضل التطبيقات المجانية ونصائح عملية تساعدك في رحلتك الدراسية.

## 🛠 الأدوات والتقنيات المستخدمة

* **إطار العمل (Framework):** [Next.js](https://nextjs.org) (App Router)
* **لغة البرمجة:** [TypeScript](https://typescriptlang.org)
* **التصميم والواجهات:** [Tailwind CSS](https://tailwindcss.com) و [ShadCN UI](https://shadcn.com)
* **قاعدة البيانات:** [Turso](https://turso.tech) (SQLite) مع [Drizzle ORM](https://drizzle.team)
* **الذكاء الاصطناعي:** [Hugging Face Spaces](https://huggingface.co) *(تم الاستعانة بـ DeepSeek و Google Gemini في التطوير)*
* **الاستضافة والنشر:** [Vercel](https://vercel.com)

## 🚀 التشغيل محلياً (Getting Started)

لتشغيل نسخة محلية من مشروع **طالب ثانوية** على جهازك، اتبع الخطوات التالية:

1. **استنساخ المستودع (Clone)**
   <div dir="ltr">

   ```bash
   git clone https://github.com/omarhossdev/thanaweya-student/
   cd thanaweya-student
   ```
   </div>

2. **تثبيت الحزم والمكتبات**
   <div dir="ltr">

   ```bash
   pnpm install
   ```
   </div>

3. **إعداد متغيرات البيئة (Environment Variables)**
   أنشئ ملف `.env.local` في المجلد الرئيسي للمشروع وأضف مفاتيح قاعدة البيانات والمصادقة:
   <div dir="ltr">

   ```env
   TURSO_DATABASE_URL=your_turso_url
   TURSO_AUTH_TOKEN=your_turso_token
   AUTH_SECRET=your_auth_secret
   ```
   </div>

   يمكنك توليد `AUTH_SECRET` باستخدام الأمر التالي: `openssl rand -base64 32`

4. **رفع هيكل قاعدة البيانات (Schema)**
   <div dir="ltr">

   ```bash
   pnpm db
   ```
   </div>

5. **تشغيل خادم التطوير**
   <div dir="ltr">

   ```bash
   pnpm dev
   ```
   </div>
